# onnxruntime-directml -- they share the `onnxruntime` namespace and vanilla
# shadows DirectML (providers drop to CPU/Azure only). Two things install it:
#   1. onnxconverter-common depends on it (don't use it; export fp16 via
#      Ultralytics `half=True` instead).
#   2. Ultralytics `.export(format='onnx')` auto-installs it during the
#      requirements check.
# So do model EXPORTS in a throwaway step, then restore DirectML with:
#   pip uninstall -y onnxruntime onnxruntime-directml
#   pip install --force-reinstall --no-deps onnxruntime-directml==1.24.4
